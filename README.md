# Victor Paul Noel — Portfolio

An interactive, responsive portfolio for Victor Paul Noel, Senior Software Engineer and Full-Stack Developer.

## Run locally

```bash
pnpm install
pnpm dev
```

## Publish on GitHub Pages

This project is configured for the `devpauln.github.io` repository. Push the project to the `main` branch, then open **Settings → Pages** and set **Source** to **GitHub Actions**. The included workflow builds and publishes the portfolio at `https://devpauln.github.io/`.

The résumé is available from the contact section, and the lightbulb in the navigation switches between light and dark themes.
